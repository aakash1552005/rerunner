# Security Policy

## Supported Versions

We release patches and security fixes for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Rerunner team takes security vulnerabilities seriously, especially because this library records and replays HTTP communications for AI agents which may involve sensitive prompt payloads or API keys.

If you believe you have discovered a vulnerability, please **DO NOT** open a public issue.

Instead, please report it via [GitHub Security Advisories](https://github.com/aakash1552005/rerunner/security/advisories/new) or send an email to:
**aakash1552005@gmail.com**

Include the following in your report:
1. Type of issue (e.g., credential leakage in cassette normalizer, memory leak, unsafe deserialization).
2. Step-by-step instructions or minimal reproducer script.
3. Affected versions.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
